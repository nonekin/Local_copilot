Загрузка документа

Основной поток: upload -> saved-> processing -> ready

Альтернативы:
неподдерживаемый формат -> отказ с ошибкой
слишком большой файл -> отказ/ограничение
Ollama недоступна -> документ остаётся failed (или “ожидает”)

Задать вопрос

Основной поток: ask -> retrieval -> answer + sources

Альтернативы:
нет релевантных chunks -> “не найдено”, sources=[]
LLM не отвечает -> ошибка 503 + сообщение пользователю

Удалить

Основной поток: delete doc -> delete chunks -> delete file

Альтернативы:
файл на диске уже отсутствует -> не критично, удалить записи
